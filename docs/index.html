Como funciona

Cinco passos simples, direto na janela do app — sem enviar nada para nenhum servidor.

1

Cole o link

Cole a URL do vídeo e clique em Carregar.

2

Veja a prévia

O vídeo toca dentro do próprio app.

3

Escolha o trecho

Arraste a barra ou marque início e fim enquanto assiste.

4

Escolha a pasta

A última pasta usada já fica salva para a próxima vez.

5

Baixe o MP3

Acompanhe o progresso e pronto — o arquivo fica na sua pasta.

Requisitos

  • Windows 10 ou 11 (64 bits)
  • Internet para carregar o vídeo e baixar o áudio
  • Não precisa instalar Python nem nada além do .exe

⚠️ Como o instalador ainda não tem certificado de assinatura digital, o Windows pode mostrar o aviso "O Windows protegeu o computador" na primeira execução. Isso é normal para apps novos e independentes — clique em Mais informações → Executar assim mesmo.

Perguntas frequentes

O UaiTiCut é gratuito?

Sim, o app é gratuito e de código aberto. Este site se sustenta com os anúncios exibidos aqui na página.

Meus vídeos/áudios passam por algum servidor?

Não. O processamento acontece inteiramente no seu computador — nada é enviado para nós.

Funciona no Mac ou Linux?

Por enquanto o instalador é feito para Windows 10/11.
